# Campus Commerce Web Platform

A full-stack course project for browsing and managing campus merchandise. The application uses PHP for server-side logic, MySQL for persistence, and HTML/CSS for the interface.

## Features

- Product browsing and merchandise pages
- User registration and login
- Database-backed account and product workflows
- Responsive styling and image assets

## Stack

PHP, MySQL, HTML, CSS

## Local setup

1. Create a MySQL database for the application.
2. Configure `DB_HOST`, `DB_USER`, `DB_PASSWORD`, and `DB_NAME` in your environment; see `.env.example`.
3. Start a local PHP server from the repository root:

```bash
php -S localhost:8000
```

This repository intentionally contains no production credentials.
